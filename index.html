1. 構成コンセプト（ヴァイパー＋チェンバー構成）

  • LOUD Haven comp（ヴァイパー＋チェンバー構成／ダブルコントローラー）
  • tkzin = Neon（ネオン）／ DaviH = Sova（ソーヴァ）／ Darker = Viper（ヴァイパー）／ erde = Omen（オーメン）／ lukxo = Chamber（チェンバー）
  • 1デュエリスト＋1イニシエーター＋2コントローラー＋1センチネル。Champions 2026（パッチ13.05）の全3試合・全69ラウンドで同一構成 ＝ Havenの固定構成
  • 戦績は3試合全勝（NRG 13-9／Vitality 13-11／決勝Vitality 13-10）、ラウンドは 39勝30敗（56.5%）。攻撃 17勝16敗（51.5%） ／ 防衛 22勝14敗（61.1%）と防衛寄りの構成
  • 数値出典: vlr.gg＋vreplay映像解析（勝敗シーケンスは全3試合でvlrの最終スコア・ハーフと完全一致を検証済み）。GIFは69ラウンド全件あり

強み

  • C設置の取り切りが最大の武器
  • → 攻撃33ラウンド中23ラウンドで設置に成功し、設置したラウンドは 14勝9敗（60.9%）
  • → 設置先はC 13回（10勝3敗／76.9%）が本命。Cに設置できればほぼ落とさない
  • → 主戦場もCが最多で 39ラウンド（23勝16敗）。Cロング経由の攻めがこの構成の軸
  • ファーストブラッドの変換率
  • → FBを取ったラウンドは 27勝10敗（73.0%、37ラウンド）と、人数有利を高い確率で勝ちに変換している
  • → FB取得の内訳は lukxo 11回・tkzin 11回・erde 8回・Darker 4回・DaviH 3回。ChamberのlukxoとNeonのtkzinが並んで最多
  • 防衛が安定している
  • → 防衛は 22勝14敗（61.1%）。DaviH＝A／Darker＝Cの固定アンカー（下記実測）が土台
  • → LOUDの勝ちラウンドの決まり手は全滅28・解除7・爆破4で、解除勝ちの多さも防衛の安定感を示す
  • フルバイ同士でも勝ち越し
  • → 両チームともフルバイのラウンドは 23勝16敗（59.0%、39ラウンド）

弱み

  • A設置は取り切れない
  • → A設置は 3勝6敗（33.3%、9回）とC設置（76.9%）と対照的。主戦場Aの交戦自体は 15勝12敗と五分以上なのに、設置後の守りで落とす形が多い
  • → Aへ攻める場合は設置前の人数差か、設置後の配置が課題（具体的な崩れ方は各ラウンドのGIFで確認する）
  • FBを落とすと取り返しにくい
  • → FBを落としたラウンドは 7勝18敗（28.0%、25ラウンド）。先に1人落ちると勝率が大きく下がる
  • Bはほぼ使わない
  • → 全69ラウンドで主戦場がBになったのは 2ラウンドのみ、設置もB 1回だけ。Bを捨てているのか、B経由の圧が記録に残りにくいのかは映像だけでは断定できないため、事実として「使われていない」ことだけを記す
  • ピストルは五分
  • → ピストルラウンドは 3勝3敗（攻撃 2勝1敗／防衛 1勝2敗）。ハーフの入りは安定していない
  • エコ・ハーフバイは落としがち
  • → LOUDがエコ／ハーフバイのラウンドは 5勝9敗（35.7%、14ラウンド）

防衛のデフォルト（実測）

  • AとCに固定アンカーを置く形が基本線（実測）
  • → vreplayの映像追跡による防衛36ラウンドの開始時点の実測（1ラウンド平均4.33人を検出）
  • → DaviHとDarkerの配置はほぼ固定で、この2人を軸に残り3人が相手に合わせて動く形と読める
  • 選手のアンカー（実測）
  • → DaviH（Sova）はAアンカー：検出31回中A 29回
  • → Darker（Viper）はCアンカー：検出32回中C 29回
  • → erde（Omen）はA寄り：A 20回／B 7回／C 6回（n=33）
  • → tkzin（Neon）はB寄り：B 19回／A 7回／C 5回（n=31）
  • → lukxo（Chamber）は流動的：C 12回／B 9回／A 8回（n=29）
  • ※ 図解はTactiValで後日追加

攻撃の形（実測）

  • Cメインの攻めが軸
  • → 攻撃の主戦場はC 20ラウンド（12勝8敗）・A 11ラウンド（4勝7敗）・B 1ラウンド
  • → 設置先もCが最多（13回）。防衛のDarkerがCアンカーなのと対照的に、攻撃でもCを取りにいくのが基本線
  • 攻撃の初期配置は実測不可
  • → 放送ミニマップの仕様で攻撃側の選手アイコンが表示されず、選手単位の初期配置は測定できない。デフォルトの形（1-3-1等）はGIFの動きからの推定になるため、ここでは断定しない
  • → 実測できるのはエントリー先（主戦場）と設置先のみで、それが上記の数字
  • ラッシュとULT合わせ
  • → 勝因判定に「ラッシュ」を含む攻撃ラウンドは 5件、「ULT」を含む攻撃ラウンドは 4件（各セクションに勝敗を掲載）。速いヒットとULTの使いどころはGIFで確認する
